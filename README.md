# 💳 Stripe Webhook Backend (Vercel Serverless)

This project is a simple **serverless backend** for handling Stripe payments and webhooks using Vercel.

---

## 🚀 What this project does

- Creates a webhook endpoint for Stripe
- Listens to successful payments
- Runs on Vercel serverless functions
- No dedicated server required

---

## 🧱 Tech Stack

- Node.js (Serverless Functions)
- Stripe API
- Vercel Deployment
